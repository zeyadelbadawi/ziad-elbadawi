# Ziad Elbadawi - Premium Digital Product Experience

## Design Guidelines

### Design References
- **Vercel.com**: Clean dark theme, bold typography, smooth animations
- **Stripe.com**: Premium feel, gradient accents, depth
- **Linear.app**: Minimal dark UI, smooth transitions
- **Apple product pages**: Scroll-driven animations, large imagery

### Color Palette
- Background: #0A0A0A (Deep Black)
- Surface: #111111 (Cards/Sections)
- Border: #1A1A1A (Subtle borders)
- Accent: #D4A843 (Gold/Yellow from logo)
- Accent Light: #F5D77A (Lighter gold for hover)
- Text Primary: #FFFFFF
- Text Secondary: #888888
- Text Muted: #555555

### Typography
- Font: Inter (clean, modern, SaaS-standard)
- Hero Name: font-weight 800, 72-96px
- Section Titles: font-weight 700, 48px
- Subtitles: font-weight 500, 24px
- Body: font-weight 400, 16px
- Mono/Tech: JetBrains Mono for tech badges

### Key Component Styles
- Cards: #111111 bg, 1px border #1A1A1A, 16px rounded, subtle glass effect
- Buttons: Gold accent bg, dark text, 8px rounded, hover glow
- Badges: Semi-transparent bg, border, small rounded
- Sections: 120px vertical padding, max-w-7xl container
